# Dynamic Documentation Maintenance Rule

## Core Directives

1. **Always Keep Documentation in Sync**:
   - Whenever creating, modifying, refactoring, or deleting code, API endpoints, schemas, environment variables, or dependencies, immediately update `PROJECT_ARCHITECTURE.md` and any associated docs files in the active branch.
   - Never finalize a task or commit code changes without updating the relevant documentation sections to reflect the current state.

2. **Source of Truth**:
   - `PROJECT_ARCHITECTURE.md` serves as the living, single source of truth for repository structure, API routes, data flow, tech stack, environment variables, known tech debt, branch status, and changelog history.
